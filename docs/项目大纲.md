- 每条断语标注出处古籍及卷目，透明可溯源。

### 5.2 ② 规则库 + LLM 润色（走 API Route）

- 先由规则库提取命局结构化特征（格局/用神/喜忌/大运走势）。
- 再把特征 + 古法约束 prompt 一起喂给 LLM，**只让它组织语言、不得引入规则库以外的新断语**。
- Prompt 硬约束示例：`仅依据以下古法规则库输出，禁止编造、禁止引用规则库外的命理结论，风格沉稳文言白话相间。`
- 后端只暴露一个 `/api/interpret` 端点；用户在 UI 上单独点"AI 润色解读"才调用。
- LLM 接口做流式输出（Streaming），一有字就吐，体感快 3-5 倍。

### 5.3 解读可选范围

用户排盘后可选是否查看解读，解读区分两个独立板块（Tab 切换）：
- **Tab 1「古法断语」**：纯古法知识库输出，零臆造，每条断语标注出处
- **Tab 2「AI 润色解读」**：规则库+LLM润色，需用户主动点击调用

### 7.1 真太阳时校正实现规范

```
校正顺序（严格按此四步执行）：
1. 钟表时间（用户输入的出生时间）
2. 夏令时还原（若为1986-1991中国夏令时期间，减1小时；
   另含1919年、1935-1937年历史夏令时判断）
3. 经度差修正（4分钟 × (出生地经度 - 120°)）
4. 均时差修正（视太阳时 - 平太阳时，范围+16分33秒至-14分06秒）

最终得到真太阳时 → 据此排四柱
```

### 7.3 来源分歧处理原则

> 对应参考来源文件 9.4 节"仍需持续关注的事项"。排盘引擎在遇到古籍版本或流派分歧时，按以下原则处理：

| 分歧类型 | 处理原则 | 说明 |
|---------|---------|------|
| **古籍版本差异** | 以四库全书本为优先，其他版本作交叉验证 | 部分古籍存在多种版本（如《渊海子平》有明嘉靖本、明万历本等），四库本经官方校勘，可靠性最高 |
| **神煞流派差异** | 遇分歧时以《三命通会》为准 | 神煞起法在不同古籍中偶有差异（如天德贵人起法），《三命通会》为明代集大成之作，体系最完整 |
| **纳音论命 vs 子平法** | 两者并存，标注口径 | 古法以年柱纳音论（《李虚中命书》），子平法以日干为核心（《子平真诠》），命盘展示时明确标注采用哪种口径 |

### 11.1 胎元三法（对应规则 #13）

参考来源 #15 标注"胎元：三法支持，默认前三百日法"。三法详列如下：

| # | 方法 | 内容 | 来源 | 大纲处理 |
|---|------|------|------|---------|
| 1 | **前三百日法（默认）** | 出生日前推三百日，以同干支日为胎元。如甲子日生→前推三百日寻甲子日为受胎之日 | 《三命通会》卷二原文（6.1） | 默认采用 |
| 2 | 月干进一位、月支进三位法 | 从月柱起，天干进一位、地支进三位。如丙寅月→丁巳为胎元 | 民间简化口诀，非古籍正法 | 可选切换，标注"民间简化法，非古籍正法" |
| 3 | 受胎月法 | 以出生月前推十个月（约三百日）所在月份为胎元月 | 综合命理资料 | 可选切换，标注"参考法" |

**实现要点**：默认使用前三百日法；用户可在设置中切换为方法2或3；无论哪种方法，命盘上均标注所用方法名称及来源。

### 11.15 命宫排法计算步骤（对应规则 #14）

参考来源 #16、《三命通会》卷二"逢卯即安命宫"（原文见参考来源 6.21）。

**口诀**："子上起正月逆数至生月，安时顺数至卯。"

**逐步算法**：
1. 从子位起正月，逆数到生月，得到生月所落地支位 A
   - 正月(寅)→子，二月(卯)→亥，三月(辰)→戌，四月(巳)→酉，五月(午)→申，六月(未)→未，七月(申)→午，八月(酉)→巳，九月(戌)→辰，十月(亥)→卯，十一月(子)→寅，十二月(丑)→丑
2. 从 A 位起，以生时地支为起点，顺数到卯
3. 卯所落的地支位即为命宫

**公式化**（生月序号：寅=1, 卯=2, 辰=3, ..., 丑=12；生时索引：子=0, 丑=1, ..., 亥=11）：
- A = (1 - 生月序号) mod 12 （结果：0=子, 1=丑, ..., 11=亥）
- 偏移 = (3 - 生时索引) mod 12 （3 = 卯的索引）
- 命宫索引 = (A + 偏移) mod 12

**验证示例**：

| 生月 | 生时 | A 计算 | 偏移计算 | 命宫 | 口诀验证 |
|------|------|--------|---------|------|---------|
| 正月(1) | 子时(0) | (1-1)mod12=0=子 | (3-0)=3 | (0+3)mod12=3=卯 | 正月→子，子起子时顺数到卯→卯 ✅ |
| 三月(3) | 子时(0) | (1-3)mod12=10=戌 | 3 | (10+3)mod12=1=丑 | 三月→戌，戌起子时顺数到卯→丑 ✅ |
| 八月(8) | 辰时(4) | (1-8)mod12=5=巳 | (3-4)mod12=11 | (5+11)mod12=4=辰 | 八月→巳，巳起辰时顺数到卯→辰 ✅ |

**实现要点**：注意生月序号按寅=1起编（非子=0体系），生时索引按子=0起编。两套索引体系不同，编码时须区分。

### 11.16 身宫排法计算步骤（对应规则 #15）

参考来源 #17、6.18《古今图书集成·艺术典》原文。

**口诀**："将本人生月支加生日支，如命顺则身逆，如命逆则身顺，数至生时支便安身宫。"

**逐步算法**：
1. 将生月支放置在生日支所在位置（即"生月支加生日支"）
2. 判断命的顺逆：阳男/阴女=命顺；阴男/阳女=命逆
3. 命顺→身逆（位置逆行）；命逆→身顺（位置顺行）
4. 从生日支位置开始，地支序列始终顺行（生月→生月+1→生月+2...），位置按身顺/身逆方向移动
5. 当序列中的地支等于生时支时，当前位置即为身宫

**公式化**（地支索引：子=0,丑=1,...,亥=11）：
- 偏移 = (生时支索引 - 生月支索引) mod 12
- 若命逆（阴男/阳女）→ 身顺：身宫 = (生日支索引 + 偏移) mod 12
- 若命顺（阳男/阴女）→ 身逆：身宫 = (生日支索引 - 偏移) mod 12

**示例**（《古今图书集成》原文例）：生月=巳(索引5)，生日=未(索引7)，生时=寅(索引2)，阴男（命逆→身顺）
- 偏移 = (2 - 5) mod 12 = -3 mod 12 = 9
- 身宫 = (7 + 9) mod 12 = 16 mod 12 = 4 = 辰 ✅
- 原文验证："从未上起巳顺数...直至辰上寅是生时便安身宫" → 身宫=辰 ✅

### 11.20 大运起运岁数精确算法（对应规则 #11）

参考来源 #7、《渊海子平》"俱折除三日为一岁"原文。

**计算步骤**：
1. 确定大运方向：阳年男/阴年女=顺排；阴年男/阳年女=逆排
2. 顺排：从出生时刻向前数，到下一个"节"（非"气"）的精确交节时刻
   逆排：从出生时刻向后数，到上一个"节"的精确交节时刻
3. 计算时间差（精确到分钟）：总分钟数 = 天数×1440 + 时数×60 + 分钟数
4. 换算为起运岁数：
   - 3天 = 1岁 → 1岁 = 4320分钟
   - 1天 = 4月 → 1月 = 360分钟（6小时）
   - 1时辰(2小时) = 10天 → 1小时 = 5天 → 1分钟 = 2小时（大运时间）

**换算公式**：
- 起运岁 = 总分钟数 ÷ 4320（取整数部分）
- 余数 → 月 = 余数 ÷ 360（取整数部分）
- 再余数 → 天 = 再余数 ÷ 12（取整数部分）
- 最终余数 → 大运小时 = 最终余数 × 2

**示例**：出生时刻到下一个节的差为10天5小时30分钟
- 总分钟数 = 10×1440 + 5×60 + 30 = 14730
- 岁 = 14730 ÷ 4320 = 3岁（余 14730 - 3×4320 = 1770）
- 月 = 1770 ÷ 360 = 4月（余 1770 - 4×360 = 330）
- 天 = 330 ÷ 12 = 27天（余 330 - 27×12 = 6）
- 时 = 6 × 2 = 12时（大运时间）
- 起运 = **3岁4月27天12时**

**实现要点**：引擎需精确计算出生时刻到目标"节"交节时刻的时间差，精度到分钟。交节时刻由节气计算层提供（太阳黄经每15°的精确时刻）。

### 11.21 拱夹虚邀判断方法（对应规则 #25）

参考来源 #20。拱夹虚邀是四柱中通过地支组合"暗拱"或"暗夹"出原本不存在的地支（虚神）：

**拱（暗拱中神）**——三合局首尾两支缺中神：

| 四柱有 | 暗拱 | 合化 |
|--------|------|------|
| 申 + 辰（缺子） | 子 | 水局中神 |
| 寅 + 戌（缺午） | 午 | 火局中神 |
| 巳 + 丑（缺酉） | 酉 | 金局中神 |
| 亥 + 未（缺卯） | 卯 | 木局中神 |

**夹（暗夹中神）**——三会局首尾两支缺中神：

| 四柱有 | 暗夹 | 会化 |
|--------|------|------|
| 寅 + 辰（缺卯） | 卯 | 木局中神 |
| 巳 + 未（缺午） | 午 | 火局中神 |
| 申 + 戌（缺酉） | 酉 | 金局中神 |
| 亥 + 丑（缺子） | 子 | 水局中神 |

**虚邀**——通过天干五合暗邀合化之五行：四柱天干有合（如甲己合），但合化之五行（土）在四柱地支中无根或极弱，则虚邀土五行到位。

**判断要点**：
1. 拱和夹的区别：拱=三合局首尾（申辰拱子），中间隔两位；夹=三会局首尾（寅辰夹卯），中间相邻
2. 半三合 ≠ 拱夹：半三合是已有两支直接相合（如申子半合水），拱夹是首尾缺中神（如申辰缺子才拱子）
3. 拱夹出的虚神力量弱于实际地支，但在格局判断中有参考价值
