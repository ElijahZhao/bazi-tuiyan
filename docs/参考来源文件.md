## 一、来源分级体系

| 级别 | 定义 | 可信度 | 用途 |
|------|------|--------|------|
| **第一级** | 国家级/国际级权威机构、国家标准 | 最高 | 天文历法数据、节气时刻、时间标准 |
| **第二级** | 命理古籍原典（四库全书本、古籍影印本） | 最高 | 排盘规则的法理依据 |
| **第三级** | 辅助参考（学术研究、开源项目、行业资料） | 中等 | 交叉验证、算法参考，不可单独作为规则依据 |

**核心原则**：
1. 命理排盘规则的权威来源是**古籍原典**，不是任何现代宗教机构或行业组织。
2. 天文历法数据的权威来源是**紫金山天文台**和**国家标准**，不是民间开源项目。
3. 当不同来源发生冲突时，以第一级和第二级来源为准。
4. 百度百科、命理论坛、博客、自媒体等**不作为规则依据**，仅供线索参考。

## 二、第一级：国家级/国际级权威机构

### 2.1 中国科学院紫金山天文台 (PMO)

| 项目 | 内容 |
|------|------|
| **机构性质** | 中国**唯一**专门研究历书天文和编算年历的国家级机构 |
| **官网** | https://www.pmo.cas.cn/ |
| **历书查询服务** | https://nddc.pmo.ac.cn/calculation/lunar （可查询 1900 年至今的公农历与二十四节气） |
| **权威领域** | 节气交节时刻、农历编算、历书术语定义 |
| **历书数据来源** | 1900-1911年以清代《时宪书》为准；1912-1948年依据《中华民国历书》和《国民历》；1949年后依据 GB/T 33661-2017 |
| **关键定义** | 节气=太阳在天球上的视位置（阳历范畴）；太阳沿黄道每走15°即一个新节气 |
| **术语页面** | http://www.pmo.cas.cn/xwdt2019/kpdt2019/202203/t20220314_6389637.html |

### 2.2 国家标准 GB/T 33661-2017《农历的编算和颁行》

| 项目 | 内容 |
|------|------|
| **标准编号** | GB/T 33661-2017 |
| **起草机构** | 中国科学院紫金山天文台 |
| **施行日期** | 2017年9月1日 |
| **权威领域** | 农历编算标准、节气黄经定义 |
| **核心规定** | 立春=太阳地心视黄经315°，春分=0°，夏至=90°，秋分=180°，冬至=270° |
| **计算规范** | 朔和节气时刻的计算依赖于太阳和月亮位置，按国际基本天文学规范（地球自转和参考系服务规范）规定的模型计算 |

## 六、已核验的古籍原文引录

### 6.1 《三命通会》卷二·论胎元

> "胎元之取，唯有一法，以当生前三百日为十月之气，乃是受胎之正。譬甲子日生便以甲子为受胎之日，盖五六计三百日，看其生日在何月中有，则闰在其中矣。且如戊子生人甲寅月乙丑日，须于半月前十月或十一月内，寻当生乙丑日，乃是三百日之正胎。"

**来源**：国学大师四库全书影印本 https://www.guoxuedashi.com/sikuquanshu/fanti/3013o/51141.html

**结论**：胎元正法为"出生日前推三百日"，非"月干进一位月支进三位"。

### 6.2 《三命通会》卷二·论大运

> "阳男阴女，大运以生日后未来节气日时为数，顺而行之；阴男阳女，大运以生日前过去节气日时为数，逆而行之。"

**来源**：国学大师 https://www.guoxuedashi.com/a/568d/14922n.html

### 6.3 《渊海子平》卷一·论起大运法

> "凡起大运，俱从所生之日，阳男阴女顺行，数至未来节；阳女阴男逆行，数已过去节，俱折除三日为一岁。
>
> 阳男阴女顺运，假如甲子年，甲己之年丙作首，正月建丙寅，初一日立春，后一日生男，顺数至二月节惊蛰，且得三十日，起十岁运，顺行丁卯。
>
> 阴男阳女逆运。假如乙丑年，乙庚之岁戊为头，正月起戊寅，初一日立春，后十五日生男。逆数至初一立春节止，得五三十五日，起五岁运，逆行丁丑。"

**来源**：东里书斋 https://huamuchengxi.com/chapter/12802.html

**结论**：阳男阴女顺排、阳女阴男逆排；3日=1岁；大运从月柱下一柱（顺排）或上一柱（逆排）开始。

### 6.5 《子平真诠》八·论用神

> "八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。
>
> 然亦有月令无用神者，将若之何？如木生寅卯，日与月同，本身不可为用，必看四柱有无财官煞食透干会支，另取用神；然终以月令为主，然后寻用。"

**来源**：中华典藏 https://www.diancang.xyz/xuanxuewushu/zipingzhenquan/53628.html

**结论**：用神专求月令；月令无用神则另取，但终以月令为主。财官印食顺用，煞伤劫刃逆用。

### 6.6 《命理探源》卷五·论时刻及夜子时

> "万育吾曰：若子时，则上半时在夜半前，属作日；下半时在夜半后，属今日。
>
> 《星平大成》云：子正者，今日之早，非作日之晚也。夜子者，今日之夜，非今日之早也。观十二生肖阴阳可知……独鼠前两只脚属阴，四爪，后两只脚属阳，五爪，故夜子时属阴，而子时正属阳。"

**来源**：国学典籍网 http://ab.newdu.com/book/ms200371.html

### 6.18 《古今图书集成·艺术典》·定身宫

> "将本人生月支加生日支，如命顺则身逆，如命逆则身顺，数至生时支便安身宫。
>
> 假如以己月加地盘生日未上看，前安命是阴男逆数者。今便从未上起，巳顺数申上午次酉上未次戌上申，直至辰上寅是生时便安身宫。"

**来源**：识典古籍 https://www.shidianguji.com/book/GJTS17/chapter/1lpfcujm83rxe

**起例歌诀**：
> "身宫轮背命垣行，月加日兮时上寻。将本人生月支加生日支，虚数至生时支止，便是安身之宫。如命顺布则星逆行，命逆行则身顺布，男女皆然。"

**来源**：识典古籍 https://www.shidianguji.com/book/GJTS17/chapter/1lpfcujm82q02

**结论**：身宫排法为"生月支加生日支，命顺则身逆，命逆则身顺，数至生时支安身宫"。

### 6.19 《李虚中命书》·四库提要（纳音论命法理依据）

> "臣等谨案李虚中命书三卷，旧本题鬼谷子撰，唐李虚中注。虚中字常容，魏侍中李冲八世孙，进士及第，元和中官至殿中侍御史，韩愈为作墓志铭，见于《昌黎文集》。后世传星命之学者皆以虚中为祖。愈墓志中所云：最深五行书以人之始生年月日所值日辰支干相生胜衰死王相，斟酌推人寿夭贵贱利不利，辄先处其年时，百不失一二者是也。"

> "详勘书中义例，首论六十甲子不及生人时刻干支，其法颇与韩愈墓志所言始生年月日者相合。而后半乃多称四柱，其说实起于宋，与前文殊相谬戾。"

**来源**：国学大师 https://www.guoxuedashi.com/a/4231r/72828j.html ；识典古籍 https://www.shidianguji.com/zh/book/SK0000A/chapter/1kgsnqnt29ste

**结论**：
1. 李虚中为后世星命之学之祖，韩愈墓志称其"百不失一二"。
2. 四库提要指出前半论六十甲子纳音属古法（年柱论命），后半四柱说实起于宋——印证了"古法以年柱纳音论命，子平法以日干为核心"的演变。
3. 六十甲子纳音释义（如"甲子天官藏，是子旺母衰之金"等）出自此书，为纳音论命之法理依据。

### 6.20 《滴天髓阐微》·上篇·天干论（十天干特性）

> "甲木参天，脱胎要火。春不容金，秋不容土。火炽乘龙，水宕骑虎。地润天和，植立千古。"
>
> "乙木虽柔，刲羊解牛。怀丁抱丙，跨凤乘猴。虚湿之地，骑马亦忧。藤萝系甲，可春可秋。"
>
> "丙火猛烈，欺霜侮雪。能煅庚金，逢辛反怯。土众成慈，水猖显节。虎马犬乡，甲木若来，必当焚灭。"
>
> "丁火柔中，内性昭融。抱乙而孝，合壬而忠。旺而不烈，衰而不穷，如有嫡母，可秋可冬。"

**任氏曰（论五阴五阳）**：
> "五阳气避，光亨之象易观；五阴气翕，包含之蕴难测。五阳之性刚健，故不畏财煞，而有恻隐之心，其处世不苟且；五阴之性柔顺，故见势忘义，而有鄙吝之心，其处世多骄谄。"

**来源**：古诗文网 https://m.gushiwen.cn/guwen/bookv_76cda085478d.aspx

**结论**：十天干特性论为日主旺衰判断之基础。甲木参天需火脱胎、春不容金秋不容土等断语，为五行调候与扶抑取用之重要参考。

### 6.21 《三命通会》卷二·论命宫

> "起命宫法，以子为正月，逆数至本生月，却就生月支上起生时，顺数至卯，卯所落地支即为命宫。逢卯即安命宫。"
>
> 又曰："命宫者，乃人之主也。命宫与命局相为表里，命宫为表，命局为里。表里相应，则吉；表里相反，则凶。"

**来源**：国学大师四库全书影印本 https://www.guoxuedashi.com/sikuquanshu/fanti/3013o/51141.html

**结论**：命宫排法为"子上起正月逆数至生月，安时顺数至卯，逢卯即安命宫"。月序以寅为正月（寅=1, 卯=2, ..., 丑=12），逆数至子起算。

## 九、来源使用规范

### 9.1 排盘规则核查流程

今后每一次排盘规则核查，必须遵循以下流程：

1. **先查本文件**：确认该规则的权威来源是第几级
2. **查古籍原文**：如果是第二级来源，核对原文引录（第六节）
3. **查天文数据**：如果是第一级来源，核对已核验数据（第五节）
4. **交叉验证**：如果来源有冲突，以第一级和第二级为准
5. **更新本文件**：如果发现新的权威来源或需修正的内容，先更新本文件再修改规则

### 9.2 禁止事项

1. **禁止**以百度百科、命理论坛、博客、自媒体作为规则的唯一依据
2. **禁止**以寿星天文历等民间项目作为节气数据的最终权威（以紫金山天文台为准）
3. **禁止**将民间简化口诀等同于古籍原文定法（如胎元"月干进一位月支进三位"≠《三命通会》"前三百日"法）
4. **禁止**以中国道教协会、中国道教学院等宗教机构作为命理排盘规则的来源（它们未发布过此类规则）
5. **禁止**在未查阅古籍原文的情况下修改排盘规则
